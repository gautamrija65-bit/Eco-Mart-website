# Eco-Mart-Website

EcoMart is an e-commerce website project designed to showcase products, allow users to sign up/login, add items to their cart, calculate the total bill, and proceed to checkout. It is built as part of my BIT coursework and personal learning in web development.

## Features
- User authentication (Login & Signup)
- Product listing with existing items
- Add to Cart functionality
- Cart section with price calculation
- Checkout process
